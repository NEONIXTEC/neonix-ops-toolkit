# 샘플데스크 제품 지식 (예시 — 가상의 서비스)

> 이 파일은 데모용 가상 서비스 "샘플데스크"(소규모 매장 예약 관리)의 고객 대면 지식 문서다.
> 실제 회사·고객·가격과 관계없다. 저장하면 재기동 없이 몇 초 안에 상담봇이 읽는다.
>
> 쓰는 규칙: 화면에 실제로 있는 것만, 메뉴·버튼 이름은 화면 글자 그대로.
> 다른 고객의 조건·이름, 내부 시스템 이름, 원가·마진, 사람 이름은 쓰지 않는다.

## 1. 예약 화면

- 예약 목록은 [예약] → [오늘] 탭에서 본다. 날짜를 바꾸려면 상단 달력 아이콘을 누른다.
- 화면은 30초마다 새로 고쳐진다. 바로 보고 싶으면 [새로고침] 버튼을 누른다.
- 예약을 옮기려면 예약 카드를 길게 눌러 [시간 변경]을 고른다.

## 2. 알림

- 예약 하루 전 18:00 에 손님에게 문자 알림이 간다.
- 알림 문구는 [설정] → [알림] → [문구 편집]에서 바꾼다. 기본 문구로 되돌리려면 [기본값으로].
- 알림을 끄려면 같은 화면에서 [예약 전날 알림] 스위치를 끈다.

## 3. 엑셀 내려받기

- [통계] → [월별] → 오른쪽 위 [엑셀] 버튼. 선택한 달의 예약 전체가 한 파일로 내려온다.

## 4. 직원 계정

- 직원 추가: [설정] → [직원] → [직원 초대]. 초대 메일의 링크로 직원이 직접 가입한다.
- 직원 권한은 [보기 전용] / [예약 관리] 두 가지다. 기본값은 [보기 전용].

## 5. 요금제 (가상 금액)

| 요금제 | 월 요금 (VAT 포함) | 예약 수 |
|---|---|---|
| 베이직 | 11,000원 | 월 300건 |
| 프로 | 33,000원 | 무제한 |

- 요금제 변경은 [설정] → [구독]에서 한다. 바꾼 요금은 다음 결제일부터 적용된다.
